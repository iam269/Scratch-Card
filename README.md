# Scratch Card 🎉

🎉 **Interactive Scratch Card Game** 🎉 - Scratch the card to reveal your prize! 🃏💰

A fun and engaging web-based scratch card game built with HTML5 Canvas, CSS, and JavaScript. Perfect for promotions, games, or just for fun! 🎮✨

## Features 🌟
- 🖱️ **Mouse and Touch Support**: Works on both desktop and mobile devices.
- 🎨 **Beautiful Gradient Design**: Eye-catching purple gradient background.
- 🏆 **Prize Reveal**: Scratch to uncover a $10 prize (or customize as needed).
- 📱 **Responsive**: Optimized for various screen sizes.
- ⚡ **Lightweight**: No external dependencies, pure vanilla JavaScript.

## How to Use 🚀
1. Open `index.html` in your web browser.
2. Use your mouse or finger to scratch the card.
3. Reveal your prize! 🎁

## Technologies Used 🛠️
- **HTML5**: Structure and Canvas element.
- **CSS3**: Styling and responsive design.
- **JavaScript**: Interactive scratching functionality.
